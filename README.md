# PandaFit — App web

Ce dépôt contient les deux fichiers statiques déployés sur Netlify :

- `index.html` — l'application tablette (connexion capteur, jeux, PandaFit Index)
- `pandafit-admin.html` — la console superadmin

Ces fichiers sont générés et mis à jour par Claude au fil des échanges avec PandaFit.
Le schéma de base de données (SQL) est géré séparément dans Supabase.
